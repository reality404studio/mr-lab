# MR Lab

Public mixed-reality and WebXR prototypes.

## Projects

- `projects/01.MIRROR`: Mirror Dance prototype.
- `projects/02.MR_TEST`: MR Snake Quest Browser prototype.
- `projects/03.TINYMYSELF`: Godeok Storage WebXR horror demo.

## Local-Only Folders

- `PRIVATE/`: work-in-progress projects and large Unity/local projects. This
  folder is intentionally ignored by Git.

## Large Assets

`projects/03.TINYMYSELF` uses local `.ply` Gaussian splat assets that are over
GitHub's normal 100MB file limit. They stay on this machine for now and should
be moved to Git LFS or external static storage before public hosting.
